# Resources
The following are some of the resources I used to help create this application.
* [Double Pendulum at University of Maryland](https://www.physics.umd.edu/hep/drew/numerical_integration/pendulum2.html)
* [Halimki and Stelea, 201-HTL-VA Differential Equations section 00001](https://gauss.vaniercollege.qc.ca/~iti/proj/2022/Ariel_Vlad.pdf) - Direct Download for a PDF. I used both of these as a sanity check for my calculations. I think this is a paper by two studetns, but it was well written so it worked well as a resource.
* [Lecture: Application of Runge-Kutta to Chaotic Dynamics and the Double Pendulum](https://www.youtube.com/watch?v=RG9waSjj2d) - Gave some context on numerical integration
* [Matplotlib's FuncAnimation by Younes Lab](https://www.youtube.com/watch?v=nT16-yQrnFk) - Used to make the animation of the Double Pendulum work
